# University of Baguio — Concern Report System (PHP / XAMPP)

PHP 8.1+ application with MySQL/MariaDB persistence. No Angular, TypeScript, npm or frontend build step. PHP handles accounts, permissions, report CRUD, database setup, PDF exports and cached map-tile requests. HTML/CSS and plain JavaScript handle browser layout and map interaction.

## Run in XAMPP — no terminal needed

1. Extract `DATABASE2-PHP` into `C:\xampp\htdocs\`.
2. Start **Apache** and **MySQL** in XAMPP Control Panel.
3. Open **http://localhost/DATABASE2-PHP/public/setup.php**.
4. Keep the demo-data checkbox checked and click **Initialize database**.
5. Click **Open login**.

The installer creates `concern_report_system`, `php_users`, and `php_reports`. Default MySQL connection: `127.0.0.1`, user `root`, blank password. If your MySQL port or password is different, copy `config.example.php` to `config.php` and update it. For a custom port, use `mysql:host=127.0.0.1;port=3307;dbname=concern_report_system;charset=utf8mb4`.

The setup page is only available from localhost. It does not reset an existing installation. For your own administrator without demo records, uncheck demo data and fill the administrator fields.

**After setup, open:** http://localhost/DATABASE2-PHP/public/index.php

### Alternative: phpMyAdmin import

Open http://localhost/phpmyadmin, choose Import, and select the included `database.sql`. It creates the database, tables, demo accounts and original sample reports. Existing matching records are not overwritten. Then open the app login page above.

## Features

- Persistent registration, login, logout, hashed passwords and PHP sessions.
- Admin: create/view/edit/delete concern reports; status changes and staff assignment; add/edit/delete student or security accounts. Administrator account deletion remains blocked.
- Student: create/view/search concern reports, edit their own reports, anonymous submission, witnesses, notes and contact information.
- Security: create/view/edit reports, change status and assign staff; no report deletion.
- All roles: map and list views, filtering, report details and downloadable PDF through the details screen. PDF is generated by PHP, not an HTML file renamed to PDF.
- Map: local Leaflet assets, actual online street/satellite imagery, same-origin PHP tile requests, on-demand caching, alternate street source, draggable location pin, clickable concern pins, red campus boundary, zoom, campus centering and Retry Online Map.
- If every online provider fails, an explicitly labeled local **coordinate grid** keeps location selection and concern pins usable. It is not satellite imagery and does not invent building locations.
- Search and status/severity filters, current statistics, redesigned campus-photo login and responsive crimson/ivory interface.
- Visible terminology consistently uses **Concern Report System**, **Concern**, or **Concern Report**.
- Share opens an email compose window containing the report URL; it does not send automatically. A localhost link only works on the same computer.

## Maps

The first tile requests need internet access from the XAMPP computer. PHP fetches only predefined public map sources for the campus area and caches requested tiles for seven days. It does not bulk-download maps. Attribution is displayed on the map. Enable the `curl` PHP extension (normally included in XAMPP); a PHP URL-stream fallback is also implemented. TLS certificate verification stays enabled. If internet access or a provider is unavailable, use the offline coordinate grid and retry online later.

## Updating the previous conversion

Replace the application code with this version while retaining your own `config.php` and database. Existing MySQL `php_users` and `php_reports` tables are compatible. No database reset is required. Do not import a database dump that drops your tables.

The earlier conversion defaulted to SQLite. This version defaults to MySQL. If you previously used SQLite, keep `storage/app.sqlite`; it is a separate data store and is **not automatically migrated**. To continue using it, set `APP_SQLITE_PATH` to its absolute path or set a SQLite DSN in `config.php`. Do not delete it thinking it has been imported into MySQL.

## Developer commands (optional)

```sh
php bin/setup.php --demo
php -S localhost:8000 -t public public/router.php
```

Initialize the MySQL database with browser setup or `database.sql` before using the CLI demo initializer. The Windows `START-DEMO.bat` now opens the XAMPP browser installer; it does not run a second web server.

## Files

- `public/`: web entry point, setup, PHP PDF export, tile endpoint, CSS, JavaScript and unchanged original media.
- `app/`: PHP controllers, permissions, database helpers, templates and bundled FPDF library/license.
- `database.sql`: importable MySQL/MariaDB schema and demo seed data.
- `config.example.php`: optional connection overrides.
- `tests/integration.py`: repeatable workflow/authorization tests. By default they use temporary SQLite; an explicit `DB_DSN` can select a dedicated test MySQL database. Never point tests at a database containing real records.
- `VERIFICATION.md`: checks and remaining limits.

Original legacy art-commission screens are retained at `index.php?page=home`, `index.php?page=analytics`, and `index.php?page=sdg-impact` with their original demo content. They are not concern analytics and are not in the concern navigation.

Source: https://github.com/M4rk0011/DATABASE2.git. Original CSS/layouts and four public media assets are retained, with local icon rendering and small-screen layout fixes. The original GitHub repository has not been pushed or changed remotely.
